# T-V2TV · 文本重建引导的视频生成研究

**状态：研究问题与源码引述已建立；尚无训练实现或实验结果。** 研究对象固定为公开的 **Wan2.1 T2V-1.3B**。本仓库以视频生成质量为最终目标，探索在仅能进行后训练的条件下，能否利用「恢复原始 prompt」的文字去噪中间态，改善动作执行、事件顺序、主体绑定和时序关系。

## 首先读什么

1. [研究问题与数学边界](docs/01_problem_definition.md)：究竟要证明什么，为什么文字重建正确不等于视频改善；区分视频帧时间、视频噪声进度、文字噪声进度。
2. [文字去噪与时序对齐的算子方案](docs/02_operator_and_alignment.md)：连续 embedding flow、离散 masked diffusion、轻量状态重建的取舍，视觉读取—文本恢复—时序写入的张量接口。
3. [固定版本的源码引述](docs/03_code_references.md)：Wan、Uni-ViGU、MDLM 的 commit SHA、文件及行号；论文/实现差异、许可与待核问题。
4. [最小证据树和实验判别](docs/04_experiment_logic.md)：先证明「读得到」「写得动」，再证明「原文重建提供增益」；保留视频供人工判断。
5. [文献与创新性边界](docs/05_literature_boundary.md)：区分已公开的联合去噪、原文重建和本文拟验证的视频侧收益。

## 中心问题

给定原始指令 `c` 和预训练视频速度场 `v_0(x_t,t,c)`，在冻结或少量适配视频骨干的前提下，学习一条保留独立文字噪声状态的反馈路径：

```text
目标 prompt ──────────────────────► Wan 原有静态条件 ─────────► 视频去噪
      │                                                        ▲
      └─► 文字腐化 z_s ─► 文字恢复器 ◄─ 当前视频状态 R(x_t)   │
                                    │                          │
                                    └─► 语义/时序反馈算子 ──────┘
```

研究目标是 **视频质量和语义执行的增量**，而不是提高文字重建准确率本身。原文始终是恢复目标；文字分支的最终结果不要求作为另一段独立生成文本交付。

## 当前冻结的选择

- **视频骨干**：Wan2.1 T2V-1.3B，使用官方模型／推理作为无修改基线。
- **预算边界**：仅做后训练；不把重新预训练视频生成器作为前提。
- **文字实现**：暂未锁定。优先验证离散 mask 的原文重建；以连续 embedding 恢复和非扩散静态语义表示为对照。
- **对齐对象**：文字 token、动作／事件短语、视频 latent 时间与空间 patch、视频去噪步骤分别标注，避免混为一个“时间”。
- **代码策略**：仅引用上游不可变 commit 的源码链接，暂不复制、改写或引入上游代码。检查依赖许可后再决定复用形式。
- **科学状态**：当前均为方法定义和静态源码核查（STATIC_ONLY / UNVERIFIED），没有声称性能提升、可训练性或完成复现。

## 最早需要排除的替代解释

文字恢复看似提高了语义一致性，可能只是（a）靠语言先验猜出被遮蔽词；（b）从已注入干净 prompt 的视频 hidden state 间接复制答案；（c）额外参数、训练时长或时序条件调度本身带来收益。文档要求分别设置对照，而不是把这些效果合并归因于“共同扩散”。
