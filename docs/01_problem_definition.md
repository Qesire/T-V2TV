# 01 · 研究问题、数学对象与可证伪命题

**研究对象**：Wan2.1 T2V-1.3B；**允许操作**：冻结视频主干，或只对选定接口做参数高效后训练；**主要目标**：视频动作、主体绑定、事件顺序和时间持续性。本文定义为研究方案，不是已实现方法。

## 1. 从生成目标出发

原始指令 `c` 在整个生成期间保持已知。原生 Wan 由 umT5 编码 `C=E_{\mathrm{T5}}(c)`，视频 latent `x` 在噪声进度上接受条件速度场 `v_0(x_t,t;C)`，最终产生视频 `\hat V`。

我们考察另一个可腐化、可恢复的文字变量 `z_s\sim q_s(\cdot\mid c)`。新增模块同时看到被腐化的文字和对当前视频的观察，恢复**同一原文**，并产生连续语义中间态 `U_{t,s}`。原有 `C` 仍供 Wan 使用。目标不是输出一段新 caption，而是让 `U_{t,s}` 改善视频。

### 三条不可混合的坐标轴

| 记号 | 轴 | 作用 |
|---|---|---|
| `f` | 视频 latent 的时间位置／帧序号 | 接近、抓握、释放等事件发生顺序 |
| `t` | **视频去噪进度**，抽象取 0=噪声、1=干净 | 当前视频状态是否可读、是否还可改变 |
| `s` | **文字去噪进度**，抽象取 0=最坏、1=干净 | 当前保留哪些文字信息 |

Wan 的实际推理调度器用下降的噪声时间戳；`t` 是本文的单调进度记号，并不直接等于源码中的 `timestep` 整数。允许 `s=g(t,x_t)`，但训练分布必须覆盖推理使用的 `(t,s)`。

## 2. 数学边界：原文恢复不增加外部信息，但可能改善计算

假设训练时取 `x_1\sim p_{\rm data}(x\mid c)`，视频噪声 `\epsilon_x` 与文字噪声 `\epsilon_z` 在给定 `c` 后独立；文字终点完全确定为 `E(c)`。于是

\[
p(x_t,z_s\mid c)=p(x_t\mid c)\,q_s(z_s\mid c).
\]

对视频流匹配的平方误差与目标速度 `u_x`，总体 Bayes 最优预测器满足

\[
\mathbb E[u_x\mid x_t,z_s,c]=\mathbb E[u_x\mid x_t,c].
\]

结论的边界是：额外文字噪声本身没有为一个已知原文、理想无限能力的去噪器提供新的视频观察。但**一个有限能力、被冻结的 Wan** 仍可能因为增加的计算结构、辅助监督和更易使用的中间表示而改善。不能把潜在收益表述成“额外增加了原 prompt 中不存在的语义信息”。

文字任务在*不直接可见目标答案*的条件下，可能从视频中获得帮助：

\[
H(c_j\mid z_s)-H(c_j\mid z_s,x_t)
=I(c_j;x_t\mid z_s)
\]

这里 `j` 是被遮蔽的目标 token，`x_t` 应当是真正携带视频证据的变量。这个量描述文字重建是否需要视觉信息，**不等于文字反馈一定帮助视频**。

## 3. 把“恢复正确”拆成可判别的功能

- **R — Read（视觉读取）**：在 `c` 的目标 token 被遮蔽后，文本去噪器预测被遮蔽动作或关系的能力是否随实际视频状态改变？固定同一个 prompt 与 mask，只替换视频、逆转帧序或改变动作。
- **A — Align（时间与对象对齐）**：文字中的动作／事件 `e` 能否与视频中的时间段 `f`、必要时空间 patch `p` 相联系？动作 A→B 与 B→A 应产生可区分的对齐。
- **W — Write（控制效果）**：固定视频状态，在有效且语义一致的局部干预下，文字恢复表示对后续视频预测或最终动作是否产生可解释的改变？
- **G — Gain（视频侧增益）**：在配对 prompt/seed、相近训练计算和推理预算下，方法相对强基线是否改善视频。`\mathcal L_{\rm text}`、token 准确率和漂亮的注意力图都不能替代 G。

主效应可以按评估源 `i`、随机种子 `r` 配对定义：

\[
\Delta_M=\mathbb E_{i,r}\big[M(\hat V^{\rm method}_{i,r},c_i)-M(\hat V^{\rm control}_{i,r},c_i)\big]
\]

其中 `M` 按动作顺序、事件完成、主体绑定、接触关系和视觉质量分别报告，而非事后挑一个容易上涨的分数。

## 4. 竞争性解释与不同预测

| 机制 | 预测 | 区分方式 |
|---|---|---|
| H0：文字依靠语言先验恢复 | 正确／错配／倒序视频对 token 预测影响弱 | 固定 `z_s`、交换视频和顺序 |
| H1：重建训练学到视觉语义，但无法控制视频 | R 阳性，W/G 不显著 | 文字分支 probe 与写入干预分开做 |
| H2：视频改善来自增加参数／普通时间路由 | 不含重建损失的同规模 adapter 也能取得同等收益 | 同接口、同训练步数、去掉 `\mathcal L_{\rm text}` |
| H3：有用的是联合演化 | 反复更新 `U_{t,s}` 胜过预计算一次且固定的 `U` | 同输入、同预算的 dynamic-vs-static |
| H4：动态文字影响事件时间分配 | 逐帧时序路由优于全局 Value-only，尤其对顺序错误 | 受控时间路由／事件对齐的因果干预 |

对 H4，输入正确的事件时间标签作为 **oracle 路由**只用于探测可控制性，不能与不使用额外信息的正常方法直接作公平性能对比。

## 5. 需要正视的非等价

### 生成过程的反事实

训练期常读到 `x_t=a_tx_1+b_t\epsilon`（真实视频加噪）；推理期读到模型自行演化的 `\hat x_t`。它们的分布可能不同。若模型在教师强制状态下正确识别动作，但在真实采样状态下不可靠，闭环反馈可能强化错误。因此 R/W 的离线结果必须接上真实生成视频测试。

### 目标信息泄漏

若重建器直接看到完整 `c`，或读取**已经通过原 prompt cross-attention 注入语义**的深层视频表示，它可能绕路复制答案。因此训练需记录重建分支可见的每个张量；先从 pre-cross-attention 视频特征或另行计算的无正向 prompt 视觉特征读取，并用错配、帧倒序及目标复制对照检查。`detach` 只能阻断梯度，不能删除信息。

### 重建不必自动产生“纠错”

目标为“拿起杯子”，当前画面却是“放下杯子”，一个准确读取画面的表示可能更强调“放下”。写入器必须同时保留目标 `C` 和当前证据 `U`，学习**朝目标修正**，而不只是增强当前画面的语义。

## 6. 研究边界和新颖性

Uni-ViGU 已公开实现共同文字—视频去噪，并在 Knowledge Recall 阶段重建原 prompt；这两项不能作为新的独立贡献。待验证的是：**固定原文目标下，恢复中间态是否能识别生成偏差，并通过时间／对象对齐的低成本反馈改善视频侧任务。** 时间引导方法与文本重建辅助监督各有先例，必须用组件与交互对照限定增量主张。
